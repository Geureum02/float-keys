# Float Keys v0.2

Changes in v0.2:
- Holdable Ctrl / Shift / Alt
- Separate Backspace and Forward Delete
- Tap shortcuts remain supported
- Meta removed from the normal editor

## Update your GitHub repo
Upload/overwrite these files in the same repo and commit to `main`. Actions will rebuild automatically. Download `FloatKeys-v0.2-debug-apk`.

## Figma duplicate
Assign one slot: **Hold modifier → Alt**. Touch and keep holding Alt, drag the object with the S Pen or another finger, then release Alt. The button dims while held.

## Delete
Use **⌦ Delete** for desktop Forward Delete. **⌫ Backspace** is a different Android key.
